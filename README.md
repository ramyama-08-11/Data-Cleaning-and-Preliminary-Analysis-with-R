# 📊 Data Cleaning and Preliminary Analysis with R

## 📌 Overview
This project focuses on **cleaning and performing preliminary analysis of a dataset using R programming**. It includes handling missing values, removing duplicates, checking data types, detecting inconsistencies, and performing basic statistical analysis.

## 🛠️ Technologies Used
- R Programming
- RStudio
- dplyr
- ggplot2
- tidyr

## 🔍 Key Activities
- Data Import
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Data Type Conversion
- Descriptive Statistics
- Basic Data Visualization

## 🎯 Objective
To prepare a clean and structured dataset and perform preliminary analysis to understand the data and identify basic patterns.
